# ✨ SkillSpark Pro — AI Resume Analyzer

SkillSpark Pro is a desktop-based AI Resume Analyzer built using Python and Tkinter. It helps users analyze resumes, detect technical and soft skills, calculate resume scores, match job roles, and generate improvement suggestions.

---

## 🚀 Features

* 📄 Upload Resume (PDF or TXT)
* 🧠 AI-based Resume Analysis
* 📊 Resume Score out of 100
* 💼 Job Role Matching
* 🛠️ Technical & Soft Skill Detection
* 📑 Resume Section Checking
* 💡 Improvement Suggestions
* 📋 Copy Analysis Report
* 📄 Export Report as PDF
* 🤖 Built-in Career Guidance Bot

---

## 🖥️ Technologies Used

* Python 3
* Tkinter
* pypdf
* reportlab
* Regular Expressions (Regex)

---

## 📦 Installation

### 1. Clone Repository

```bash
git clone https://github.com/Kishore7-web/SkillSpark-Pro.git
```

### 2. Open Project Folder

```bash
cd SkillSpark-Pro
```

### 3. Install Required Libraries

```bash
pip install pypdf reportlab
```

---

## ▶️ Run the Project

```bash
py main.py
```
